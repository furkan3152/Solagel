# Discord and Telegram assets

Re-run from the repo root:

```
node brand/community/generate.mjs
```

| File | Size | Use |
| --- | --- | --- |
| `server-icon-512.png` | 512×512 | Discord server icon (Discord crops it to a circle or squircle; the coin stays inside) |
| `discord-banner-960x540.png` | 960×540 | Discord server banner (16:9); the wordmark and coin still read at the 240 px sidebar size |
| `telegram-header-1280x640.png` | 1280×640 | Telegram group header: the image for the pinned welcome post or channel header, with the four arena tickets |
| `telegram-photo-640.png` | 640×640 | Telegram group photo (Telegram crops it to a circle) |
