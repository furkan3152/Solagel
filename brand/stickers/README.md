# Sticker and emote pack

Thirteen coin characters for Discord and Telegram, die-cut (paper border, ink cut line, off-register riso shadow) on
transparent 512×512 PNGs, plus 128×128 copies in `emoji/` for Discord custom emoji. Text on the stickers is English
only. Re-run from the repo root:

```
node brand/stickers/generate.mjs
```
