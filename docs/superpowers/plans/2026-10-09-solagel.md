# Solagel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Solagel, a cute coin-themed on-chain Agar.io for Solana: Anchor program (identity, stakes, seasons, prizes), authoritative game server with smart bots, and a polished web client.

**Architecture:** Hybrid. A 30 Hz authoritative Node server runs the physics and bots; everything involving value, identity, rankings and rewards lives in the `solagel` Anchor program. The client renders on Canvas 2D with React overlays and talks to the server over a binary delta protocol and to Solana through Wallet Standard wallets.

**Tech Stack:** pnpm workspaces · TypeScript 5 · Node 22 · `ws` · Vite + React 19 · zustand · Anchor 1.2.1 (Rust 1.97.1 host, sBPFv3) · LiteSVM 0.17 · `@anchor-lang/core` 1.2.1 · `@solana/web3.js` 1.x · wallet-adapter · vitest · Playwright (screenshots).

**Spec:** `docs/superpowers/specs/2026-10-09-solagel-design.md`

## Global Constraints

- Program ID comes from `target/deploy/solagel-keypair.json` (not committed); `declare_id!`, `Anchor.toml`, SDK default and env defaults must agree.
- Radius `r = 10·√m`; start mass 20; eat ratio 1.25; eat overlap 0.4; split min mass 35; max cells 16; merge `12 s + 0.015·m`; eject cost 18 / blob 14; virus mass 100, pop ratio 1.33; decay 0.15 %/s above 150; max cell mass 12 000; tick 30 Hz.
- Level `1 + ⌊√(xp/50)⌋`; skins 0–7 free, 8–15 level-gated at [2,3,5,7,10,13,16,20], 16–23 premium.
- Fee only on profit, `fee_bps ≤ 1000` (default 500), season share of fee default 5000 bps; prize shares (bps) `[3000,2000,1400,1000,800,600,450,300,250,200]`; leaderboard size 20; refund timeout 24 h; claim window 30 days.
- Stake rooms never contain bots. Value transfer `t = ⌊V_b·m/M_b⌋` lamports, all-in when last cell dies.
- Server forces cash-out at session age 6 h; refunds never-connected sessions after 15 min.
- No real token logos; every skin is an original drawing.
- UI copy exists in TR and EN; default from `navigator.language`.
- Chain features must degrade gracefully: missing program/RPC/keypair → free play keeps working.

## Review Focus

- Server restart or crash while stake players are alive → every live player is auto-cashed-out from the journal at last snapshot value; vault never pays more than it holds. (Task 5 test `journal recovery settles live players`.)
- User rejects or cannot afford a wallet transaction (join/register/buy) → UI returns to the previous state with a readable error, never stuck in "pending". (Task 11 `useTx` error path + manual check.)
- Program not deployed / RPC unreachable → lobby shows "on-chain offline" and Free Play still works; server boots without chain. (Task 8 test `chain disabled when env missing`; Task 11 detection.)
- Two cells at exactly the same position (dist = 0) or NaN/Infinity input targets → physics stays finite. (Task 4 tests `coincident cells stay finite`, `invalid input ignored`.)
- Phone-width screens and touch-only devices → HUD panels do not overlap, joystick + buttons usable. (Task 10 Playwright mobile screenshot.)
