# Elymum: read it yourself (about 100 seconds of talking)

You're telling a friend how a little game works. Warm, dry, slightly amused. You're not selling
anything. Talk, don't announce: no lift at the end of every line. Let the short lines be short,
and let the pauses make the jokes.

`/` take a small breath · `//` hold a beat · `(pause)` a longer stop · **bold** lean on it a little

---

1. You are small change. // With a **big** appetite.
2. Which, / around here, / is a perfectly good career.
3. This is Elymum. // Coins eat coins, / on Elysium's ring.
4. Rounds last **five** minutes. / One bell, / for every arena at once.
5. When it rings, / whoever's still alive gets paid. // Whoever isn't (pause) was lunch.
6. Getting in is short. // Join the WL. / Mint your Elymum NFT, / one dollar in HYPE. // Then play.
7. Pick a room. / Buy a ticket. // In you go.
8. Right. / You're the little one. // Don't take it personally.
9. Smaller than you? // **Dinner.** // And whatever they were worth / is yours now.
10. Bigger than you? // Leave. / Don't make eye contact. / Just leave.
11. Press space, / and you split in two. // One half lunges.
12. The other half / tries to look casual.
13. Final minute. // Joins close. / Nobody new gets in, / and everyone gets a little **careful.**
14. Big coins slow down. / Small coins get ideas.
15. Ten seconds. // Keep your head down. (pause) Coins don't have heads. / Keep it down anyway.
16. Still here at the bell? // Then it's **yours.** / Paid out, / minus five percent of the profit.
17. Elymum. // Join the WL. / Follow **@elymumio.** // And bring an appetite.

---

**Say it like this:** Elymum = *EL-ih-mum*. Elysium = *ih-LIZ-ee-um*. WL = *double-u L*.
HYPE = *hype*. NFT = *N-F-T*. @elymumio = *at elymum eye-oh*.

**Recording:** a quiet room with soft things around you (a wardrobe of clothes is ideal), the
mic a hand's width from your mouth and a little to the side. Keep a glass of water close.
Leave 3 seconds of silence at the start of the file (that's the room tone). Read each numbered line
once, then wait a slow count of two (at least 1.5 s) before the next one, so the lines can be
cut apart by the silence. If you fluff a line, stop, wait, and read the whole line again; before
you send the file, cut out the bad take, so it holds exactly 17 lines. Keep your breaths: they're
meant to be there.

**The file:** WAV, 48 kHz, 24-bit (44.1 kHz or 16-bit is fine too), mono, no effects, peaks
around -6 dB. Name it `vo-human.wav`. Or save one file per line named after its line id:
`hook_a hook_b what_a what_b what_c flow lobby drop first_eat run split_a split_b final_a final_b
ten paid close` (for example `vo-human/first_eat.wav`).
